# M.S.F — مساعد مبيعات قصر الكلاسيك

نسخة تطوير أولية محسّنة لتطبيق الويب التقدمي (PWA).

## الميزات
- إدارة المنتجات بالاسم والكود والفئة والسعر والخصم والمخزون والوصف.
- حفظ حتى 3 صور مضغوطة لكل منتج.
- تعديل المنتجات وحذفها والبحث بالكود أو الاسم أو الفئة.
- حاسبة السعر النهائي والتوفير والتنبيه عند خصم 20% أو أكثر.
- بحث صوتي عربي عندما يدعمه المتصفح.
- تصدير CSV ونسخة احتياطية JSON كاملة واستعادة النسخة الاحتياطية.
- الحفاظ على مفتاح التخزين السابق لترحيل المنتجات الموجودة على الجهاز.

## ملاحظات مهمة
- البيانات محفوظة محليًا في المتصفح على الجهاز نفسه.
- النسخ الاحتياطي JSON يتضمن الصور؛ احتفظ به في مكان آمن.
- لا توجد مزامنة سحابية بين الأجهزة في هذه النسخة. تحتاج هذه الميزة إلى خادم وقاعدة بيانات وإعداد صلاحيات.
- جرّب النسخ الاحتياطي قبل استبدال النسخة المنشورة.
